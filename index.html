PROJ_02Installation de GLPI sur Debian Linux 12
GLPIDebian LinuxMariaDBApache
▾

L'entreprise fictive Biovision souhaite mettre en place un outil de gestion du parc informatique et du helpdesk. Ma mission : installer et configurer GLPI sur une VM Debian 12 avec synchronisation LDAP vers le domaine Biovision.com.

OBJECTIFS
  1. Configurer la machine Debian avec IP statique (172.16.140.30)
  2. Installer Apache2, PHP et MariaDB
  3. Créer la base de données GLPI et configurer les répertoires
  4. Configurer le VirtualHost Apache pour Biovision.com
  5. Finaliser l'installation via l'interface web GLPI
TRAVAIL RÉALISÉ
  • Installation Apache2 + PHP + MariaDB + paquets PHP (ldap, curl, gd...)
  • Création BDD glpi_admin, déploiement GLPI 10.0.10, configuration VirtualHost biovision.com
  • Installation complète via l'assistant web GLPI (6 étapes)
  • Configuration des notifications par mail via SMTP / Postfix — test de création et suivi de ticket d'incident
COMPÉTENCES
